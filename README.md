A little fun Middleware Projects to help with my learning;

Type of Middleware I work on in this Project are:
1. Body-Parser Middleware (for pre-processing requests before they get to the Server).
2. Morgan Middleware (for logging requests before they get to the Server/DB).
3. Custom Middlware (this one is fun because you get to create and name a function, then call it in your app.use()).


Before you see how the code works in your localhost:3000

- cd into your folder
- install npm by:  npm i
- the run nodemon: nodemon index.js or use nodemon to run any of the files
